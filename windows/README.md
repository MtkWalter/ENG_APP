# Milo English — Windows 桌面版 2.3.0

適用 Windows 10 / 11 **64 位元 x64**，建議 8 GB RAM。Windows ARM 電腦可使用系統的 x64 模擬；此版本未提供原生 ARM64，也不支援 Windows 7 / 8。

## 使用方式

1. 先關閉舊版 Milo，再執行 `Milo-English-Windows-2.3.0-x64-Setup.exe` 安裝，或直接開啟 `Milo-English-Windows-2.3.0-x64-Portable.exe`。另提供 ZIP，解壓縮後執行 `Milo-English.exe`。右下角應顯示 v2.3.0。
2. 開啟就能在右側玩內建主題，不必登入 ChatGPT 或等待 AI 產生題目。選早餐店、公園、教室、動物或旅行，再選庫洛米／大耳狗與玩法。需要 AI 輔助教學時，再到左側登入自己的 ChatGPT 帳號。
3. 點一下對話中的英文單字，右側立即顯示英文、KK 音標、繁體中文；也可在右上方輸入英文查詢。字典不需要網路或 API key。
4. 拖曳選取同一則訊息內的英文句子，可使用離線模型翻譯。首次按右下方「下載離線模型」，約需下載 120 MB；之後在本機 CPU 執行，不將選取文字傳至模型下載服務。一次最多 5,000 字元，較長內容分段處理。
5. 「朗讀」改用 Windows 原生語音引擎產生音訊，並在 Milo 播放；「0.5× 慢讀」以半速播放並保留音高。同一段文字重播或切換速度可重用記憶體中的音訊，減少等待；快取有容量上限，關閉程式即釋放，不寫入磁碟。右下方「測試聲音」可單獨確認。優先選英文語音，缺少英文時會使用系統語音並提示；若完全沒有語音，請到 Windows「設定 → 時間與語言 → 語音」安裝。

網頁左側選單、聊天紀錄與帳號欄保留，由使用者透過網頁原本的按鈕自行展開或收合。對話文字維持加寬；收合左側選單後會使用騰出的空間。從 2.0.1 升級時，舊的側欄隱藏設定會被忽略。上方 Milo「新對話」仍可直接開始新對話。

上方「語音專注」預設開啟，沿用 Android 版隱藏文字輸入、附件、模型選單及語音動畫的設定。關閉此開關可恢復文字輸入、附件與模型選擇，適用登入、需要打字，或網站版面更新的情況。側邊字典留在同一個視窗，查字不會跳到其他 App。

離線整句翻譯是選用功能，一直連網也能使用；不下載模型也能查內建單字及使用 ChatGPT 網站語音。

2.0.4 在長對話優化之外，修正平滑捲動時新文字跟不上的情況，並支援網站分階段建立訊息。快速切換翻譯時重用已載入的模型，只保留最新待處理的文字，避免反覆建立模型與累積過期工作。取消會在模型的生成步驟之間生效，正在執行的單一步驟仍需完成。

快捷鍵：`Ctrl+N` 新對話、`Ctrl+R` 重新載入聊天、`Ctrl+L` 查字、`Esc` 清除查詢。`A− / A＋` 調整聊天頁面縮放並記住設定。Milo 顯示時保持螢幕開啟，最小化後解除螢幕限制；ChatGPT 仍在播放音訊時，另維持防止程式休眠的請求，播放停止後解除。

若 Milo 內的 ChatGPT 語音說到一半停住，而同台電腦的瀏覽器語音正常，可按上方「瀏覽器語音 ↗」開啟目前這段對話，再啟動瀏覽器語音。瀏覽器需自行登入同一個 ChatGPT 帳號；Milo 的圖片遊戲與字典仍留在原視窗。

## 右側遊戲：由 Milo 直接執行

2.3.0 移除「先傳送指令給 ChatGPT、等教材 JSON 回覆才能開始」的遊戲流程。遊戲畫面、出題、答案判定、提示、拼字、句型、星星、拼圖、餵食與闖關都由 Milo 執行。開啟即有完整內建教材；AI 不參與遊戲計分或關卡狀態。

三種教材來源：

| 來源 | 使用方式 |
| --- | --- |
| 內建題庫 | 早餐店、公園、教室、動物、旅行，各 6 個單字與 3 題句型；每輪共 15 個任務。選主題，按「開始玩」即可。 |
| 英文圖片 | 按「載入圖片，辨識英文」。程式在本機辨識文字，再用內建字典挑單字，從原句建立練習；不向 ChatGPT 上傳圖片或傳送出題指令。 |
| 自己的教材 | 在下方文字框貼上或修改英文，按「用這份文字開始遊戲」。需要至少 3 個有中文釋義的內容單字；最多 12,000 字元。 |

圖片辨識包含英文語言資料與引擎，不需另下載模型。使用 PNG、JPEG 或 WebP，原檔最多 20 MB、3,200 萬像素；會校正方向、移除中繼資料與整理尺寸，原檔不改動。辨識在背景 Worker 執行，最多同時一個工作，完成或取消後釋放。辨識期間原本的遊戲仍可玩，不改動聊天頁面的語音專注或草稿。

**圖片需要清楚的英文文字。** 純物件照片、手寫、模糊或太小的文字可能無法建立教材。這時保留原本關卡，請修改文字框的辨識結果，或先選內建主題。圖片文字辨識可能有誤，不把無法辨識的內容假裝成圖片事實。

圖片／文字教材每輪挑選 3–6 個已收錄釋義的單字，優先練原句的 be 動詞與有中文線索的原句填空。只有單字、沒有合適句子時，補上內建基礎句型，並在教材來源明確標示，不冒充圖片原句。其他題目的文字與例句保留原始教材內容，未做 AI 文法修正。

| 玩法 | 操作與獎勵 |
| --- | --- |
| 益智拼圖 | 先記憶意思，再點打散字母拼字，最後完成句型；完成一題揭開一片夥伴拼圖。 |
| 寵物點心屋 | 完成練習得到點心，按「餵一份點心」親手餵庫洛米或大耳狗。 |
| 任務闖關 | 通過記憶、拼字、句型三階段，查看進度與星星，答對後按「下一關」。 |

獨立第一次答對得星星；提示或重試後也能完成任務。重複按同一題不重複領獎，沒有點心時不能餵食。關卡文字、例句、解說與獎勵不依賴聊天回覆。遊戲進度是本輪記錄，換主題、重新挑戰或關閉程式後重新開始。

「聽發音」使用 Windows 原生朗讀，讓你聽讀、開口跟讀與聽寫；不錄音或自動評分發音。拼字題不直接顯示答案；拼圖玩法提供打散字母。展開「夥伴與玩法」可更換角色或玩法，再按「套用夥伴／玩法，重新挑戰」，沿用本輪教材，不重新辨識或上傳。

移除圖片會清理預覽與暫存檔，已建立的本輪遊戲仍保留。辨識失敗、取消或輸入無效教材不會用其他單字冒充新教材，也不會清除原本的遊戲。

## AI 輔助教學（選用）

展開「AI 輔助教學」，可選看圖對話、文法句型或看圖測驗。這三種模式才會把圖片與教學要求送到目前登入的 ChatGPT，讓 AI 協助角色扮演、解說或一次一題練習。需要網路、帳號及圖片權限，不必設定 API key。它們與本機遊戲分開，AI 失敗不會破壞原本關卡；選回「學習遊戲」即可繼續。

AI 圖片教學保留文字輸入框，方便回答；已有草稿或附件時會停止，避免覆蓋。上傳狀態不明不自動重送；取消後須檢查 ChatGPT 輸入區。只有選用 AI 模式時圖片才會傳給 ChatGPT，本機遊戲與本機圖片文字辨識不會。

## 資料、字典與翻譯

- 保留 Android 2.0.0 APK 中的 `study_dictionary.db`、來源授權與四個原始介面腳本，來源提交為 `096f0b024a316690e15ae05d60683ca0c197750b`。Windows 使用 src/page 中針對長對話最佳化的介面腳本，點字擷取沿用原始腳本。原檔雜湊記錄於 `assets/android/integrity.json`，啟動時驗證字典完整性。
- 共 142,153 個詞條，其中 KK 125,112 筆、中文 100,497 筆；兩種收錄範圍不同。KK 是 CMUdict 美式 ARPABET 轉寫，不是 Yahoo / Dr.eye 原稿。缺少音標會顯示「尚未收錄」，不以其他詞形的音標代替。
- 整句模型為 `Xenova/opus-mt-en-zh`，固定 revision `046f55aec303cdee3e0318604406d4df20f1e8ea`，來源為 Helsinki-NLP OPUS-MT，使用 ONNX Runtime CPU 及 OpenCC 繁體轉換。模型下載完成後，推論明確禁止遠端模型存取。模型翻譯及字典釋義都可能與上下文不符。
- 登入狀態由獨立 Chromium session 儲存；設定與模型放在 `%APPDATA%\Milo English`。免安裝版也使用此目錄，所以移動 EXE 不會帶走登入資料。程式不保存查詢紀錄，也不讀取剪貼簿或匯出 Cookie。
- 只有明確點字、拖曳選取或在字典欄輸入的文字會送到本機字典 / 翻譯模組。ChatGPT 網站本身的對話及收音仍由網站處理。

## 常見狀況

- **ChatGPT 無法載入**：檢查網路後重新載入。右側離線字典仍可使用；上方「瀏覽器語音」可開啟正常網站。瀏覽器中的內容不具備 Milo 點字及介面調整功能。
- **ChatGPT 語音說到一半停住**：若瀏覽器正常，先用「瀏覽器語音」接續同一對話。也可戴耳機，或在網站暫時關閉麥克風再聽一段，以協助區分喇叭回音觸發插話與其他原因；程式不會替你自動開關麥克風。2.2.2 起補強背景播放與專注模式控制項，但尚未證實使用者實際帳號的中斷原因。
- **圖片無法建立遊戲**：確認圖片有清楚英文，檢查並修改辨識文字；至少需 3 個有釋義的單字。內建主題可直接玩，不必等待 AI。
- **手動可附圖，但 Milo 顯示找不到附件按鈕**：請升級至 2.2.1，修正新版中英文附件選單、工具列在表單外的版面，以及 125%／150% 縮放時點擊位置偏移。找不到可辨識的附件入口時，會嘗試將已選圖片直接拖放至確認的輸入區，不讀寫剪貼簿。若先前已手動附圖但尚未送出，請先送出或清空，避免和新課程一起傳送。
- **登入方式受限制**：網站可能不允許嵌入瀏覽器使用部分第三方登入。可嘗試 ChatGPT 的電子郵件登入；外部瀏覽器的登入不會自動搬進 Milo。
- **麥克風沒有聲音**：按「麥克風設定」重設 App 權限，再啟動語音。也請確認 Windows 已允許桌面應用程式使用麥克風及選到正確輸入裝置。只允許 ChatGPT 請求音訊，攝影機與螢幕擷取不開放。
- **朗讀沒有聲音**：按「測試聲音」，再檢查 Windows 音量混音器中 Milo 的音量與輸出裝置。2.0.1 改用 Windows 原生語音，會顯示合成或播放失敗的原因，不再因瀏覽器語音列表空白而直接停止。
- **版面改變 / 按鈕不見**：關閉「語音專注」可恢復完整網站。網站的 DOM 結構改變可能需要更新腳本。
- **離線翻譯失敗**：重新下載模型；確認有約 300 MB 可用空間及足夠記憶體。網路中斷後可再次下載，已完成的模型檔會沿用。
- **安裝來源提示**：這是未購買程式碼簽章憑證的版本，Windows 可能顯示發行者未知。可用隨附 `SHA256SUMS.txt` 比對來源與檔案完整性。

## 從原始碼建置

在 Windows 安裝 Node.js 24 LTS（含 npm），於本資料夾執行：

```powershell
npm ci
npm test
npm run test:desktop
npm start
npm run build:win
```

產物位於 `dist/`，包含安裝版、免安裝版、ZIP。建置與執行都不需要 Python、Android SDK、Visual Studio 或 NVIDIA CUDA；原生推論元件使用預建 N-API 套件。打包時會附上本機 Microsoft Visual C++ x64 執行階段 DLL，讓目標電腦可以直接載入推論元件；建置電腦若缺少它，請先安裝 Microsoft 官方 VC++ 2015–2022 x64 Redistributable，或用 `MILO_CRT_DIR` 指定可再散布的 CRT 目錄。

`npm run test:translation` 為額外的實際模型推論檢查，首次會下載模型。可用 `MILO_MODEL_DIR` 指定測試快取目錄；測試會重啟 worker，再用禁止遠端模型存取的設定執行推論。

`npm run test:media` 使用虛擬音訊裝置，實際測試 Chromium 麥克風擷取、指定喇叭、攝影機拒絕及本機 WebRTC。接收串流接到真正的 HTMLAudioElement 持續播放至少 15 秒，跨查字、字幕更新、縮放、切換焦點及最小化／還原，確認封包、播放時間與音訊能量持續增加，並檢查播放期間的休眠限制與結束後釋放。報告僅記錄計數與狀態。`npm run test:speech` 在 Windows 使用實際語音引擎產生非靜音 WAV；打包後 EXE 也會重新執行同一項檢查。這些測試不代表已登入真實 ChatGPT 完成語音通話，也不代表已聽到使用者電腦的喇叭聲音。

`npm run test:performance` 對照長對話逐字更新的全頁查詢、屬性寫入與畫面更新耗時，並驗證手動捲動、選字、底部操作區避讓、平滑捲動及分階段建立的新訊息。分析與可重現方式見 [效能分析](PERFORMANCE.md)。

`npm run test:images` 在實際 Electron 的模擬 ChatGPT 頁面驗證圖片檔案事件、三種選用 AI 課程自動傳送、兩種角色、重複載入、草稿保留與取消。此測試不使用帳號，不能代替現行 ChatGPT 的實際圖片上傳與語音驗證。打包後 EXE 另確認影像處理的原生元件與角色資產隨程式提供。

`npm run test:upload` 驗證 15 種上傳相容情境，包含新版中英文選單、外置及巢狀輸入區、125%／150% 縮放、真實檔案拖放、送出後重建輸入框、草稿／PDF 保護，以及不誤用頭像上傳欄位。停用的網站控制與未接受圖片的狀態會停止並提示，不會重複送出；右側圖片仍保留。

`npm run test:ocr` 使用隨程式提供的英文圖片與語言資料，實際辨識並建立題目；`npm run test:games` 在實際 Electron UI 走完三種遊戲、五個主題、文字教材與真正的圖片辨識，確認向 AI 傳送訊息 0 次、上傳圖片 0 次，並驗證聊天頁面移除後仍可玩、取消或無效教材保留原關卡、獎勵不重複，以及 Windows 原生遊戲朗讀。打包後 EXE 也重新執行本機圖片辨識與題庫檢查。

`.github/workflows/windows.yml` 在 Windows runner 執行單元測試、Electron 合成頁面測試、打包與產物校驗，產出可下載的 artifact。測試頁面攔截 `https://chatgpt.com/`，不使用帳號或讀取真實對話。

測試範圍：真實內建字典、缺字提示、來源限制、選字上限、跨行內格式點字、句子選取、專注模式恢復、縮放、斷網查字、取消舊查詢、設定與模型快取。合成頁面測試無法確認現行 ChatGPT 網站、真實帳號登入、實際語音通話或每台 Windows 的語音裝置；這些仍須在使用者電腦驗證。

Milo 並非 OpenAI 官方 App，ChatGPT 的介面、支援情況與服務權限由服務提供者控制。
