Windows 10 / 11 x64 版 2.1.0：圖片英文學習，以及庫洛米／大耳狗陪學單字遊戲。

按上方或右側「圖片學習」，選模式與遊戲角色，再載入一張圖片。Milo 會把圖片和教學指令送到目前的 ChatGPT 對話，直接開始所選活動，不需另設 API key。

- 看圖對話：主動選情境，用短回合、小故事帶著說英文，不先反覆詢問程度和目標。
- 文法句型：依圖片教一個實用句型，示範後立即填空或造句。
- 看圖測驗：一次一題，回答後再給提示或解答，五題一輪。
- 單字遊戲：選庫洛米或大耳狗陪學，五關收星星。每關分開練發音和拼字；不把文字回答冒充真正的發音評分。要練口說，請開啟 ChatGPT 網站語音。

支援 PNG、JPEG、WebP；20 MB、3,200 萬像素以內。原檔不改動，方向校正、移除中繼資料後適度縮圖，上傳前提供本機預覽。更換模式或角色後可用同張圖片再次開始。

開始圖片學習會關閉「語音專注」並顯示文字輸入區，方便回答題目與拼字。仍可開啟 ChatGPT 網站語音，傳送完成後也能自行恢復精簡語音畫面。

保留原生左側選單與收合按鈕、文字加寬，以及 2.0.4 的長對話、翻譯取消與朗讀重播優化。原有字典與選用的離線整句翻譯仍可使用。

若 ChatGPT 輸入區有草稿、附件或正在回覆，會停止並提示，避免覆蓋內容。取消、導航、逾時或無法確認送出時不自動重送。請關閉「語音專注」檢查未送出的內容。清除本機圖片不會刪除 ChatGPT 對話中的圖片。

需要網路、登入 ChatGPT，且帳號可使用圖片上傳。圖片辨識、教材回應、遊戲回饋與語音能力由網站提供；已測試實際 Electron 的模擬上傳流程與打包後影像元件，雲端未使用使用者帳號完成真實 ChatGPT 圖片／語音課程。網站版面更新可能需要調整相容程式。

下載 Setup.exe 安裝，或直接執行 Portable.exe，兩者皆不需要登入 GitHub。請先完全關閉舊版再開啟新版，確認右下角顯示 v2.1.0。登入與個人設定沿用原本的 Milo 資料目錄。
