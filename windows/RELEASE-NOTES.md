Windows 10 / 11 x64 版 2.0.4：改善文字跟隨、快速選句與重複朗讀的等待。

- 修正網站啟用平滑捲動時，逐字更新不斷重啟動畫、最新文字跟不上的情況。手動往上看與選字仍會暫停跟隨。
- 支援網站先建立空白對話回合、稍後才加入內容；新訊息仍可正確加寬和跟隨。程式碼與清單逐段出現時不掃描整份歷史。
- 快速切換翻譯文字時重用同一個模型，只保留最新待處理的選取，取消舊內容的生成；避免反覆卸載、重載原生模型造成停頓或載入失敗。
- 同一段文字重播或切換 0.5× 慢讀時，重用已產生的音訊。快取只存在記憶體，上限為 8 筆、8 MiB，不寫入磁碟。

延續長對話顯示優化：

- 逐字更新略過整段歷史掃描，加寬排版只處理新訊息，減少重複的樣式寫入。
- 快取捲動容器與底部操作區，內容換行時才更新跟隨，尺寸改變時才重新計算避讓空間。
- 改善手動往上看、滑鼠拖動及鍵盤捲動時被自動拉回的情況；選取文字時暫停跟隨。
- 保留原生側欄控制，以及 Windows 原生朗讀、語音權限、字典與翻譯功能。

600 則歷史訊息、120 次文字更新的本機模擬中，全域查詢從 360 次降為 0 次，Milo 排版屬性寫入從 36,060 次降為 0 次。畫面更新回呼耗時的單次本機結果由約 480.1 ms 降至 22.2 ms；這不是整個 ChatGPT 頁面或模型回覆速度的同等加速，實際效果仍受電腦、對話與網站本身影響。測試與方法見原始碼內的 windows/PERFORMANCE.md。

- 保留 ChatGPT 網頁左側的選單、聊天紀錄、帳號欄及原本的收合按鈕，由使用者自行操作。移除 Milo 自動隱藏側欄的程式與設定，升級後也會忽略 2.0.1 留下的隱藏設定。
- 對話文字維持加寬，使用者手動收合側欄時可顯示更多內容。
- 修正網站音訊輸出裝置選擇權限，補齊音訊裝置列舉與同來源語音框架的權限判斷；麥克風仍需允許，攝影機與螢幕擷取維持關閉。
- 「朗讀／0.5× 慢讀」改用 Windows 原生語音引擎產生音訊，改善瀏覽器語音清單為空時沒有聲音的情況。新增「測試聲音」按鈕與明確錯誤提示。
- 離線整句翻譯維持選用，不下載模型也能查內建單字與使用 ChatGPT 網站語音。

下載 Setup.exe 安裝，或直接執行 Portable.exe。兩者皆不需要登入 GitHub。可覆蓋安裝；登入與個人設定沿用原本的 Milo 資料目錄。

測試包括：從舊設定升級後側欄與收合按鈕保留、網頁自行收合及展開、重新掛載後保留網頁的收合狀態、文字寬度、真實內建字典、Chromium 音訊擷取、指定喇叭、攝影機拒絕、本機 WebRTC 音訊封包、Windows 原生引擎產生非靜音 WAV，以及打包後 EXE 的朗讀驗證。

目前無法使用使用者的 ChatGPT 帳號在雲端重現實際通話；安裝後請重新測試網站語音。若聲音仍未播放，請按「測試聲音」，並確認 Windows 音量混音器中的 Milo 輸出裝置。這是預覽版，未配置程式碼簽章。
