Windows 10 / 11 x64 版 2.2.2：修正圖片遊戲教材接收，補強語音播放與專注模式。

- 修正 ChatGPT 收合長題目並顯示「顯示較多」時，已回傳教材卻無法開始右側遊戲。支援回覆前的思考標題，仍檢查本輪識別碼、完整結尾與題目格式；不點擊網站展開按鈕。
- 教材準備完成後只收合本輪題目與回覆，保留其他對話，可用「查看教材」展開。
- 語音專注保留字幕及說話、暫停、繼續等語音控制，避開包含實際音訊的動畫容器，減少字幕更新引發的歷史掃描。
- ChatGPT 播放期間維持防止程式休眠的請求，最小化時也保留；停止播放、換頁或關閉時釋放。這不會自動開關麥克風。
- 上方「瀏覽器語音 ↗」直接開啟目前對話，供同台電腦瀏覽器語音正常時使用。瀏覽器須登入同一個帳號。

新增長題目收合的整個遊戲流程回歸，以及至少 15 秒真正接上播放裝置的本機 WebRTC 測試，涵蓋字幕串流、查字、縮放、焦點切換與最小化／還原。保留四種圖片課程、庫洛米／大耳狗、三種遊戲、原生朗讀、字典、翻譯及長對話測試。原生左側選單仍由使用者自行收合。

目前合成頁面尚未重現使用者實際 ChatGPT 語音中斷；上述改動與測試不能保證所有帳號及網路都不中斷。若 Milo 內語音仍停住，可先用「瀏覽器語音」接續目前對話。

請先完全關閉舊版，再開啟 2.2.2，確認右下角版本。圖片遊戲請重新依圖片出題，以取得新一輪教材；舊版已逾時的回覆不會自動套用。登入與個人設定沿用原資料目錄。

Setup.exe 與 Portable.exe 皆免登入 GitHub 下載。附件含 README-Windows.md、PERFORMANCE.md、SHA256SUMS.txt。此為未配置程式碼簽章的預覽版。
