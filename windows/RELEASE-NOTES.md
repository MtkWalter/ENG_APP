Windows 10 / 11 x64 版 2.2.0：用圖片玩解謎、餵夥伴與英文闖關。

「圖片學習 → 單字遊戲」新增三種原生玩法，可選庫洛米／大耳狗陪學：

- 益智拼圖：單字記憶配對、打散字母重排拼字、句型填空；完成一題就揭開一片夥伴拼圖。
- 寵物點心屋：完成練習賺點心，親手按按鈕餵夥伴；點心餘額與已餵數量依實際操作更新。
- 任務闖關：記憶 → 拼字 → 句型，三階段逐題前進，顯示完成數、星星及回饋。

教材開始時由目前登入的 ChatGPT 根據圖片準備，通過檢查後就在 Milo 內即時答題。每題不用再呼叫 ChatGPT；換夥伴或玩法可沿用教材重玩，不重傳圖片。獨立第一次答對得星星，提示或重試也能完成任務；答對後提供例句／句型解說。同一題不能重複領獎，餵食只消耗已賺到的點心。

「聽發音」使用 Windows 原生語音示範，支援跟讀與聽寫；不錄音、不自動判斷玩家發音。句型回答填入缺字或片語。遊戲進度為本輪記錄，重玩、更換課程或關閉程式後重置。

本輪教材在聊天畫面預設收合，避免直接露出答案；可按「查看教材」展開，沒有刪除網站訊息。原生左側選單仍保留，由使用者自行收合。

保留四種圖片學習模式、圖片預覽與取消、原有字典、選用的離線整句翻譯、Windows 朗讀及長對話優化。圖片支援 PNG／JPEG／WebP，原檔上限 20 MB、3,200 萬像素，不改寫原檔。

等待教材可取消，舊題、格式錯誤或不完整的教材不會直接啟動遊戲。教材讀取器只在準備時工作，完成後解除，不持續掃描聊天歷史。草稿、其他附件、導航與不明送出狀態會停止自動傳送。

完成功能後再次優化畫面更新：闖關／寵物玩法不建立隱藏拼圖，提示或回饋不重建相同拼圖；只有新進度或角色改變才更新圖塊。保留 600 則長對話逐字更新的效能回歸檢查。

背景字典翻譯完成時只更新原查詢，不會把正在進行的遊戲切回字典；新選取單字時仍會正常開啟查字畫面。

需要網路與可上傳圖片的 ChatGPT 帳號，不需額外 API key。已用實際 Electron 的模擬頁驗證流程、原生遊戲規則與打包元件；尚未登入使用者帳號驗證現行 ChatGPT 的真實圖片辨識與教材回覆。網站版面與模型輸出可能影響教材準備。

下載 Setup.exe 安裝，或直接執行 Portable.exe，皆免登入 GitHub。請先完全關閉舊版再開新版，確認右下角 v2.2.0；登入與個人設定沿用原資料目錄。
