Windows 10 / 11 x64 版 2.2.1：修正「手動可上傳，但 Milo 找不到圖片附件按鈕」。

- 支援新版 Add files and more、繁體中文附件按鈕與上傳選單。
- 辨識工具列在表單外、巢狀輸入區、關聯的外置檔案輸入框與選單。
- 修正 125%／150% 網頁縮放時點錯附件或傳送位置，改用與頁面量測一致的點擊座標。
- 找不到可辨識的附件入口時，嘗試把已選圖片拖放到確認的輸入區；使用真正的圖片檔案，不讀寫剪貼簿。
- 保留草稿、其他附件與頭像欄位保護；停用的網站功能會明確提示。網站尚未接收圖片時停止，右側圖片仍保留，可再重試。

新增 15 種實際 Electron 相容性回歸情境，並重測四種圖片課程、三種遊戲、原生朗讀及長對話效能。另支援送出後網站重建輸入框，避免已傳送卻誤判失敗；不會因此再次傳送。這是模擬 ChatGPT 版面的上傳測試；尚未登入使用者帳號驗證現行網站的自動上傳。網站版面、圖片額度與模型輸出仍可能影響使用。

保留庫洛米／大耳狗、解謎拼圖、寵物點心屋、任務闖關、字典、翻譯及既有效能優化。原生左側選單繼續保留，由使用者自行收合。

請先完全關閉舊版，再開啟 2.2.1，確認右下角版本。若先前已手動附圖而尚未送出，請先送出或清空 ChatGPT 輸入區，再用 Milo 載入圖片。登入與個人設定沿用原資料目錄，不需變更帳號或網路設定。

Setup.exe 與 Portable.exe 皆免登入 GitHub 下載。附件含 README-Windows.md、PERFORMANCE.md、SHA256SUMS.txt。此為未配置程式碼簽章的預覽版。
