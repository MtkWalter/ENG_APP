## 網頁文字放大、縮小

上方小型 **A−／A+** 每次增減 10%，可調 80%–160%，即時套用並保存；不必重新載入網頁。「⋮ → 字體大小設定」也可調整，返回後立即套用。App 按鈕保持原大小。

此控制適用 App 內的網頁。另開 Chrome 或「瀏覽器語音視窗」時，請使用該瀏覽器本身的字體／頁面縮放設定。

## 長按選字，彈出網路翻譯與 KK

1. 長按 ChatGPT 網頁文字，拖曳選取單字或整句。
2. 點文字選單的 **「網路翻譯／KK」**。
3. 查詢視窗自動連網查詢，不用輸入 API key，也不用登入 ChatGPT 才能查字。

單字依序顯示 **英文 → KK 音標 → 繁體中文**。片語／整句顯示英文與中文，不顯示 KK。中文可翻成英文；若譯文是單字，也會查英文 KK。保留朗讀與 **0.5 倍慢讀**，查詢不自動出聲。

中文翻譯使用 **MyMemory** 的免金鑰服務；KK 取自 **Yahoo 奇摩字典** 明確標示的 KK 欄位。視窗會顯示來源，並提供「查看網路字典」連結。不呼叫 OpenAI 查詢 API、不使用 Google 翻譯、不讀取聊天帳號憑證。先前的查詢金鑰欄位及設定按鈕已移除。

字典未提供 KK、限制連線或版面改變時，會顯示「暫無可靠 KK 音標」，保留成功的中文翻譯，不以 IPA 或假資料替代。可重新查詢或直接開來源核對。免費翻譯來源有長度與每日用量限制，每次約可處理 500 個 ASCII 英文字元（中文較少）；超出時會提示縮短或稍後再試，不截斷原文。已成功的完整查詢會保存在本次 App 程序的 100 筆記憶體快取中。

外部 Chrome 的選字動作仍叫「Milo 查詢」；若選單沒有列出，可複製後回查詢視窗貼上。
