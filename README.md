## 預設隱藏 App 內網頁的語音球

針對使用者先前圈出的 ChatGPT 藍色語音球，新增網頁圖形隱藏處理。預設啟用，語音開始後新出現的圖形也會重新判斷。

只處理辨識到的語音圖形，不移除語音停止按鈕、麥克風按鈕、載入指示、對話文字及訊息裡的圖表。不讀取登入憑證、不複製對話到 App，不呼叫或改動網站的音訊 API，也不重新載入頁面。

如需還原，開啟「⋮ → 顯示語音球」；設定會保存。這個選項只改顯示，無須停止或重開對話。

**僅適用 Milo 內嵌網頁。** Chrome／「瀏覽器語音視窗」由瀏覽器與網站控制，App 無法修改其中的網站畫面。若目前使用的是瀏覽器視窗，關閉該視窗返回 Milo，選「App 內網頁（可調文字大小）」才能使用本版圖形處理；原有 WebView 語音相容性限制仍可能存在。
