## 選取單字或整句翻譯

1. 在 ChatGPT 網頁長按英文單字。
2. 拖曳選取範圍，可擴大成片語或整句。
3. 在文字選單點 **「Milo 翻譯」**；有些瀏覽器會放在「⋮」或更多選項中。
4. 出現中文翻譯後，可按「朗讀英文」或「0.5 倍慢讀」。查詢時不會自動出聲干擾語音聊天；朗讀前可先暫停網站的麥克風。

若文字選單沒有 Milo 翻譯：複製選取文字，再用瀏覽器最上方「⋮ → 貼上文字翻譯」，或關閉聊天視窗回 Milo，點「選字／句子翻譯」手動貼上。也可將純文字分享給 Milo 翻譯。

翻譯使用 Google ML Kit 的手機端英文／中文模型，**不需要 OpenAI API key**。首次需連網下載缺少的語言模型，約數十 MB，畫面會顯示準備狀態；完成後可離線翻譯。模型下載失敗可重試。Android 10 以上將中文輸出轉為繁體字；Android 8／9 保留模型提供的中文。純中文可翻成英文。最多接受 6,000 字元，超過會提示縮短，不會把整句靜默改成單字。

這個功能接收的是你明確選取或貼上的文字，不讀取網頁整頁內容、登入 Cookie 或密碼。翻譯在手機上執行；朗讀由手機文字轉語音服務提供。KK 及進階情境查字仍保留在 API 學習模式。

## 語音一直轉圈的調整

你已確認同一帳號在手機瀏覽器可正常語音，只有 App 的內嵌 WebView 一直轉圈。新版預設改用瀏覽器提供的 App 內視窗，優先使用 Chrome，讓瀏覽器處理網站登入、WebRTC 與麥克風權限；沿用該瀏覽器的正常登入狀態，不用填 API key。

關閉網站視窗會回 Milo，不會自動反覆重開。沒有支援 App 內視窗的瀏覽器時，會改用一般瀏覽器開啟。右上方選單保留「分享 Milo App」下載連結及貼上翻譯入口。

原本內嵌網頁保留在「App 內嵌網頁（相容模式）」，補上音訊設定權限、調整遠端語音播放設定，並修正首次麥克風授權畫面暫停 App 時過早取消網站請求的情況。內嵌網頁與 Chrome 的登入仍各自保存，不會複製或擷取帳號憑證。
