# Milo 英文練習 1.7.0

[下載 1.7.0 APK](https://github.com/MtkWalter/ENG_APP/raw/refs/heads/apk-download/Milo-English-v1.7.0.apk)

本版預設進入 **Milo 原生左右對話泡泡**，以 App 內登入的 ChatGPT 網頁文字為來源。聊天不需要另外填 API key。可直接覆蓋更新，與 1.6.0 使用相同簽章。

## 第一次使用

1. 開啟 App，點左上「網頁」或下方「登入／網頁語音」。
2. 在 App 內的 ChatGPT 網頁登入現有帳號，選擇或建立對話。
3. 點左上「對話」，已呈現的文字會同步成 ChatGPT 在左、你在右的 App 對話泡泡。
4. 可從 App 輸入訊息並送出；App 操作一般網站輸入框和送出按鈕，等網頁真的出現對應訊息才清空 App 草稿。遇到網站忙碌、已有草稿、尚未登入或送出未確認時，保留草稿並提示檢查網頁，不自動重送。

**Chrome 與 App 的登入各自保存。** 手機瀏覽器已登入仍需在 App 內登入一次，App 不會從 Chrome 取得登入憑證。

## 語音與原生畫面

原生泡泡畫面不顯示網站的藍色語音球。使用語音時，先點「登入／網頁語音」，從網站開始、暫停或停止；可再切回「對話」看原生文字。切回網頁仍保留網站原有介面，沒有刪除網站的停止按鈕。

使用者先前手機瀏覽器語音正常、WebView 一直轉圈的問題，**本版尚未證實修好**。網站在 WebView 的語音相容性仍由手機及網站決定；選單保留「瀏覽器語音視窗」，但該瀏覽器的對話無法讀回 App。若網站拒絕內嵌登入，也只能改用瀏覽器，不能保證此模式可用。

## 選字查詢與字體

AI 泡泡可長按、拖曳選單字或整句，再點「Milo 查詢」。查詢卡仍使用 1.6.0 的獨立 OpenAI API 設定；本次免 key 指的是網頁來源聊天，**不包含自動翻譯／KK 卡片**。

- 單字：英文原文 → KK 音標 → 繁體中文。
- 片語／整句：英文原文 → 繁體中文，不顯示 KK。
- 保留英文朗讀及 0.5 倍慢讀，不自動出聲；沒有 Google 翻譯套件。
- 「⋮ → 字體大小設定」可調整 80%–160%，套用到原生文字、查詢卡及相容 WebView；操作按鈕維持原大小。

## 同步範圍與限制

這是實驗性的網站頁面同步，不是官方 ChatGPT 客戶端 API。只讀取目前網站已呈現的文字，約每 1.5 秒同步，最多最近 60 則、每則 12,000 字元、總計 200,000 字元。附件、圖片、完整歷史及帳號操作仍由網站處理。網站改版、尚未載入或驗證限制可能導致同步失敗，App 會提示，不把示範內容當成網站回答。

腳本不讀 Cookie、storage、密碼或 token，不呼叫私有端點，也不繞過登入／網站驗證。網頁對話不混入原有 API 模式的本機對話庫；舊 API 模式與瀏覽器替代方式保留。
