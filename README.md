# Milo 1.8.1 選字查詢相容修正

[下載 1.8.1 APK](https://raw.githubusercontent.com/MtkWalter/ENG_APP/apk-download/Milo-English-v1.8.1.apk)

可直接覆蓋更新，簽章與 1.8.0 相同。

部分手機選好文字後，選單沒有出現「網路翻譯／KK」。本版補上 Activity 層選單入口，並在網頁上方加入固定「翻譯」按鈕。

1. 在 App 網頁選好文字，點上方「翻譯」。
2. 若文字選取被網站取消，先長按並「複製」，再點「翻譯 → 貼上並查詢」。此流程不依賴手機的自訂選字選單。
3. 外部瀏覽器的查詢項目也統一叫「網路翻譯／KK」；是否列出仍由瀏覽器決定。若沒列出，可複製後回 Milo 查詢視窗貼上。

貼上功能只在按「貼上並查詢」時讀取剪貼簿文字，不會在背景自動讀取。查詢維持免 API key：翻譯使用 MyMemory，KK 使用 Yahoo 奇摩字典。單字依序顯示英文、KK、中文；句子不顯示 KK。保留 0.5 倍朗讀與網頁 A−／A+ 字體大小設定。

來源有每日流量與每次 500 UTF-8 bytes 限制；超長時提示縮短，不截斷內容。字典無法提供可靠 KK 時會明確顯示暫缺，保留翻譯與查看來源連結。

122 項 Android/JVM 測試通過，0 失敗、0 錯誤、0 跳過；Debug APK 編譯成功，Lint 0 錯誤、2 項提示。新增驗證 Activity 選單入口、固定翻譯按鈕無選取時的手動視窗，以及明確按下貼上才查詢的流程。

尚未在 OPPO 實機驗證選單修正。真實 Yahoo／MyMemory 連線仍受雲端出站規則限制，不能以合成測試聲稱已驗證網站目前相容性。ChatGPT 語音轉圈問題本次未確認修好。
