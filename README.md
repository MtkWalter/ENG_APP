Android 8.0 以上。簽章與舊版相同，可直接更新安裝，無須先移除 App，原有設定與對話會保留。

## 這次更新

- 移除「中英自動」及手動語言選擇按鈕。手機語音服務可能忽略上一版的自動切換要求，這次改由 AI 直接轉錄原始錄音，讓模型自行辨識中文、英文與混合語句。
- 辨識請求不指定語言，不會先把你的中文翻成英文當作原話；中文以繁體呈現，英文保留英文。
- 設定新增「個人 OpenAI API key」，可直接連 OpenAI，不必另架後端。舊有後端模式仍可選擇。
- 底部保留精簡的開始／停止、暫停／恢復、重新一輪；維持較大的文字對話區。

## 安裝後如何使用

1. 開啟 App，點右上角設定。
2. 選「個人 OpenAI API key」，在手機貼上自己的 `sk-…` 金鑰，按「儲存設定，開始練習」。請勿把金鑰貼到聊天裡或提供給其他人。
3. 按「開始對話」，允許麥克風權限，直接說中文或英文。每句說完停頓約一秒，AI 轉錄後回覆並朗讀；朗讀完成後自動接著聽，直到按停止。

OpenAI API 需有可用額度，費用與 ChatGPT 訂閱分開計算。個人金鑰以 Android Keystore 加密後保存在本機，固定送至 OpenAI HTTPS 服務，不傳至自訂網址。錄音不存檔，每句會上傳至所選 AI 服務做轉錄；此功能需要網路。

預設離線體驗只有示範文字及小型字庫，沒有 AI 語音辨識，按開始會引導連線。若使用自己的舊後端，需更新至包含 `/api/transcribe` 的新版後端，或改用上述個人金鑰模式；更新 APK 不會替你部署後端。

## 保留的功能

英文陪練為主，中文可作為卡住時的輔助；AI 朗讀期間不收音。暫停收音不會打斷 AI 朗讀，停止則同時結束朗讀。重新一輪會清除本輪上下文。長按拖曳選取單字或句子可翻譯、查 KK、聽 0.5 倍慢速朗讀。右上角可分享目前版本下載連結，不附帶對話、錄音或金鑰。

離開 App 或開翻譯／設定會暫停收音；取消後晚到的轉錄不會加入對話。已上傳至 AI 的音訊無法收回。
