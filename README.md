# Milo 英文練習 1.1.0

[下載 1.1.0 APK](https://github.com/MtkWalter/ENG_APP/raw/refs/heads/apk-download/Milo-English-v1.1.0.apk)

適用於 Android 8.0 以上，可直接覆蓋安裝舊版，簽章相同。首次開始語音對話時，請允許麥克風權限。

## 這版可以怎麼用

- 按「開始語音對話」後，說英文、自動送出、聽 AI 回覆，AI 說完自動接著聽，直到按「停止對話」。
- 「暫停麥克風／恢復麥克風」獨立控制收音；暫停麥克風仍可讓 AI 完成回覆。AI 朗讀時不收音。
- 長按文字，拖曳選取單字、片語或句子，再點「翻譯／發音」。也可點「翻譯整句」捷徑。單字保留 KK 查詢。
- 慢速朗讀為 0.5 倍，支援選取的單字或整句。
- 右上角「分享這個 App」開啟手機分享選單，傳送這一版 APK 的下載連結給其他人。

手機需有支援美式英文的語音辨識與朗讀服務，可從 App 設定前往手機語音設定。離開 App 或開翻譯／設定時會暫停收音，回來後按恢復繼續。

App 預設仍為明確標示的離線體驗。真正的 ChatGPT 對話沿用自己的 API 後端設定。分享連結不包含本機聊天或憑證，其他人需自行設定後端。
