## 最新回覆被底部輸入／語音操作區擋住

使用者回報 2.0.0 的避讓沒有達成預期。本版依最後一行實際文字與當下可見的底部區域計算捲動位置，處理以下情況：

- 輸入區尚未套用精簡標記時，也會預留底部空間。

- 忽略隱藏的舊輸入區，使用目前可見的控制區邊界。

## 沿用的學習功能

點英文單字會顯示「英文 → KK 音標 → 繁體中文」小視窗，不切換其他 App，不需要 API key。長按可選整句，整句不顯示 KK。保留朗讀及 0.5 倍慢讀。

內建約 125,112 筆美式發音及 100,497 筆英中釋義，收錄範圍不完全相同。KK 根據 CMUdict 美式 ARPABET 發音轉寫，使用 KK 記號及音節起首規則放置重音，並非 Yahoo 原始 KK，也不把 ECDICT 的英式 IPA 改名為 KK；未收錄的發音不猜測。中文詞義來自 ECDICT，建置時轉成繁體。來源與授權見 [DICTIONARY-LICENSES.txt](DICTIONARY-LICENSES.txt)。

整句及缺少釋義的詞使用 Google ML Kit 裝置端翻譯，首次需要下載語言模型，之後可離線使用。Android 10 以上轉成繁體，Android 8／9 沿用模型的中文結果。沿用前景亮屏、麥克風系統授權重用、精簡按鈕和語音球隱藏。
