# Milo 英文練習 1.2.0

[下載 1.2.0 APK](https://github.com/MtkWalter/ENG_APP/raw/refs/heads/apk-download/Milo-English-v1.2.0.apk)

Android 8.0 以上，可直接覆蓋安裝舊版；簽章相同，連線設定和對話保留。首次使用語音時允許麥克風權限。

## 這次更新

- 放大文字對話的顯示空間：縮小標誌和留白，移除整條連線提示、常駐打字按鈕與長按操作說明。
- 底部精簡為單列「開始／停止對話、暫停／恢復收音、重新一輪、語言」按鈕。
- 中文、英文或中英混合都可以說，練習方向仍以英文對話為主。
- 預設英文優先的中英自動辨識；手機服務不支援或中文不準時，點最右側語言按鈕手動選中文／英文。語言選擇會保存，不會清除對話。
- 按「重新一輪」確認後清除本輪訊息與上下文；原本正在語音對話時會接著開始新一輪。取消則保留本輪。

## 保留的功能

按開始即可持續說話、送出、聽 AI 回覆，AI 說完自動繼續聽，直到按停止。暫停收音不會打斷 AI 回覆；AI 朗讀期間不開麥克風。長按拖曳選取單字或句子可翻譯、聽 0.5 倍慢速朗讀。右上角可分享本版本下載連結。

手機需有支援中英文的辨識服務與英文 TTS 語音。Android 14 以上會請求自動語言切換，但是否支援及語言模型是否就緒取決於手機服務；其他情況可手動選語言。離開 App 或開翻譯／設定時暫停收音，回來按恢復繼續。

離線體驗改在 AI 名稱旁以「離線示範」小標示，回覆仍為示範內容。真正的 ChatGPT 對話沿用自己的 API 後端；更新 APK 不會替你部署後端。新版後端原始碼的陪練提示允許中文輔助並維持英文練習，但已部署服務需自行更新提示；原版後端本來也接受中文。
