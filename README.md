## 畫面調整

App 上方只保留「新對話、A−、A+」，縮為一列小按鈕。移除標題、網址、分享、選單、翻譯按鈕及「網頁文字 %」。字體仍可每次調整 10%，範圍 80%–160%，設定會保存。

ChatGPT 網頁底部在能辨識語音控制時，只顯示麥克風及語音按鈕。隱藏輸入框、附件、模型選單與頁尾提示；語音使用中的送出、停止等操作仍保留。沿用藍色語音球隱藏處理，不更改網站音訊 API。這些調整只適用 Milo 內嵌網頁，外部 Chrome 視窗由瀏覽器控制。

## 選好文字後自動翻譯

先在手機安裝 **Google 翻譯 App**。在 Milo 內長按文字，拖曳選取單字或句子；選取穩定約 0.9 秒後，自動開啟 Google 翻譯，不必再點「翻譯」。未安裝時會提示安裝，不改開翻譯網站。

已移除先前 MyMemory、Yahoo／Dr.eye 網頁查詢與自製 KK 卡片。翻譯、語言及發音由 Google 翻譯 App 提供，不需要 API key；其發音記號不保證是 KK。

只將明確選取的文字交給 Google 翻譯 App，不讀取 Cookie、登入頁、剪貼簿、整頁對話或正在編輯的文字。最多 5,000 字元，超過會提示縮短，不截斷內容。外部瀏覽器仍須依該瀏覽器的文字處理選單操作。

App 在前景保持亮屏，已取得的 Android 麥克風權限可重用。開啟 Google 翻譯等其他 App 時，原有前景收音管理仍會停止網站收音；回到 Milo 後可能需要重新開始語音。
