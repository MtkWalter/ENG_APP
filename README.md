## 查詢的顯示順序

- **單字：英文原文 → KK 音標 → 繁體中文。**
- **片語／整句：英文原文 → 繁體中文，不顯示也不請求 KK。**

在聊天網頁長按單字，拖曳可選整句，再點文字選單的「Milo 查詢」。卡片會自動開始查詢，不必再按「翻譯」。查過的內容可從本次 App 記憶體快取立即顯示；第一次查詢仍需等待網路與 AI 回覆。

如果瀏覽器沒有列出 Milo 查詢，可複製文字後從瀏覽器頂部選單「英中＋KK 查詢」，或回 Milo 首頁開卡片貼上。保留英文朗讀及 0.5 倍慢讀；查詢不自動出聲，以免被網頁的語音聊天收進去。

## App 內自動查詢卡需要個人 OpenAI API key

**ChatGPT 網頁登入不等於 API 授權。** App 不能讀取或擷取網站憑證來替代 API key。若要直接在 App 卡片填出中文和單字 KK，請在卡片下方輸入一次自己的 OpenAI API key，按「儲存金鑰並查詢」。API 費用與 ChatGPT 訂閱分開計算。

查詢金鑰以 Android Keystore 加密保存在手機，與瀏覽器登入及原有聊天設定分開；如果 API 聊天已啟用個人金鑰，也可沿用。沒有金鑰時會明確說明，不把假內容當查詢成功。

不填 key 的替代方式是「改用現有 ChatGPT 帳號查詢」：複製查詢提示並開啟 ChatGPT，需自行貼上送出，結果顯示在網頁，**不會自動填回 App 卡片**。Chrome 本身也不會在你結束選取時通知 Milo，因此仍需點一次選字選單的「Milo 查詢」。

KK 由 AI 產生，供學習參考；沒有可靠音標時明確標示，不捏造來源，不將 IPA 主重音或斜線音標直接標成 KK。

## 字體大小設定

查詢卡右上角、Milo 首頁與瀏覽器頂部選單均有設定入口。可調整 80%–160%、查看英文／KK／中文預覽，按「套用字體大小」保存。返回卡片後會直接調整已顯示內容，不重新發送 API 查詢；操作按鈕維持原大小。

套用範圍為 Milo 查詢卡、原生對話及內嵌相容網頁。ChatGPT 的 Chrome 網頁仍需使用 Chrome 本身的字體／頁面縮放設定。

## 藍色語音球

圖片紅圈內的是 ChatGPT 網站的藍色語音球，不是載入圈。Chrome 網頁視窗無法由 Milo 直接隱藏這個網站元素，**本版沒有移除它**。Milo 原生 API 對話介面沒有語音球，但需要自行設定 API 連線。
